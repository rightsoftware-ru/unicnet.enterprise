## Файлы запуска

Основной compose.yml описывает приложения и задания инициализации. Два небольших дополнения compose.pg.yml и compose.keycloak.yml добавляют встроенные PostgreSQL и Keycloak. Готовые примеры выбирают один из четырёх составов без изменения YAML.

В entrypoints/ находятся только три коротких адаптера запуска. Они передают сгенерированное окружение приложениям и подготавливают встроенный Keycloak. Эти файлы требуются опубликованным образам, поэтому их нужно распространять вместе с Compose.

Инициализатор поставляется готовым образом unicnetinit. В репозитории установки нет его исходников, Dockerfile, сборки, Python-установщика и тестовой обвязки. Версии образов задаются в `.env`; адреса образов указаны в Compose-файлах.

<a id="repository"></a>
## Файлы в репозитории

- `README.md` — описание продукта, статус пилотной поставки и порядок получения доступа.
- `INITIAL_DEPLOYMENT.md` — основная инструкция установки на Linux с четырьмя вариантами развёртывания.
- `User.Guide.UnicNet.v1.9.pdf` и `User.Guide.UnicNet.v1.9.docx` — руководство по использованию продукта.
- `compose.yml`, `compose.pg.yml`, `compose.keycloak.yml` — состав служб и зависимости запуска.
- `.env.example` и `infrastructure.example.json` — настройки варианта со встроенными PostgreSQL и Keycloak.
- `examples/external-postgres.env` и `examples/external-postgres.json` — вариант с внешним PostgreSQL.
- `examples/external-keycloak.env` и `examples/external-keycloak.json` — вариант с внешним Keycloak.
- `examples/external-both.env` и `examples/external-both.json` — вариант с обеими внешними службами.
- `frontend-settings.example.json` — исходный файл настроек интерфейса; его копия заполняется приложением.
- `registry-token.txt` — общий токен поставки для скачивания Docker-образов, используемый с именем `oauth`.
- `entrypoints/app.sh`, `entrypoints/postgres.sh`, `entrypoints/keycloak.sh` — необходимые адаптеры запуска контейнеров.
- `docs/` — схема служб, подключение внешних систем, первый вход и эксплуатация.
- `.gitignore` и `.gitattributes` — исключение рабочих файлов из Git и сохранение Linux-окончаний строк скриптов.

Распространяйте перечисленные файлы вместе, сохраняя структуру каталогов. Общий токен скачивания образов включён в репозиторий по решению поставщика. Лицензия, настройки клиента и реквизиты его служб создаются или передаются отдельно. Тестовые стенды, протоколы приёмки и внутренняя инфраструктура поставщика в состав установки не входят.

## Настройки и данные

.env задаёт адрес, сеть устройств, версии образов и состав Compose. infrastructure.json описывает подключения к PostgreSQL и Keycloak. Рабочие файлы с реквизитами, лицензией и настройками интерфейса исключены из Git.

Секреты генерируются один раз и хранятся в закрытых volumes. Каждый сервис читает только свой файл окружения. Имя проекта unicnet-docker-test сохранено для совместимости имён volumes; не меняйте его у установленного стенда.

Данные хранятся в volumes и frontend-settings.json. После настройки не подменяйте базу, realm, режимы служб и лицензию без отдельной процедуры. Эта поставка предназначена для первоначального развёртывания, не для автоматического обновления и резервного копирования.
