## Файлы запуска

Основной compose.yml описывает приложения и задания инициализации. Два небольших дополнения compose.pg.yml и compose.keycloak.yml добавляют встроенные PostgreSQL и Keycloak. Готовые примеры выбирают один из четырёх составов без изменения YAML.

В entrypoints/ находятся только три коротких адаптера запуска. Они передают сгенерированное окружение приложениям и подготавливают встроенный Keycloak. Эти файлы требуются опубликованным образам, поэтому их нужно распространять вместе с Compose.

Инициализатор поставляется готовым образом unicnetinit. В репозитории установки нет его исходников, Dockerfile, сборки, Python-установщика и тестовой обвязки. Версии и контрольные digests опубликованных образов перечислены в IMAGES-rc-init-test.json.

## Настройки и данные

.env задаёт адрес, сеть устройств, версии образов и состав Compose. infrastructure.json описывает подключения к PostgreSQL и Keycloak. Рабочие файлы с реквизитами, лицензией и настройками интерфейса исключены из Git.

Секреты генерируются один раз и хранятся в закрытых volumes. Каждый сервис читает только свой файл окружения. Имя проекта unicnet-docker-test сохранено для совместимости имён volumes; не меняйте его у установленного стенда.

Данные хранятся в volumes и frontend-settings.json. После настройки не подменяйте базу, realm, режимы служб и лицензию без отдельной процедуры. Эта поставка предназначена для первоначального развёртывания, не для автоматического обновления и резервного копирования.
