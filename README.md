# UnicNet

UnicNet — программный продукт компании «ПРАВИЛЬНЫЙ СОФТ» для обнаружения и учёта сетевых устройств, построения карт сети, автоматизации управления и расследования событий.

<a id="features"></a>
## Функциональные возможности

1. Автоматизация поиска и опознания сетевых устройств по протоколам SNMP, SSH, Telnet, Redfish, IPMI. Возможность получения базовых данных от устройств, не имеющих поддержку указанных протоколов на уровне сети.
2. Автоматизация наполнения базы данных устройств и возможность выгрузки базы в текстовые и табличные форматы.
3. Ручное наполнение базы устройств, ручная правка сведений в базе.
4. Автоматическое и ручное создание сетевой карты по протоколам LLDP, CDP, MNDP, участков сети, подсетей. Выгрузка карты в формате изображения и Visio. Конструктор карт для ручного добавления устройств и связей на любую имеющуюся карту.
5. Просмотр пути прохождения трафика по протоколу STP. Просмотр статусов и статистики портов, VLAN, состояния устройств.
6. Взаимодействие с устройствами по доступным протоколам в формате CLI в ручном режиме.
7. Группировка и назначение тегов группам устройств, отдельным устройствам, наследование тегов, использование тегов и групп в рамках модуля Runbook
8. Runbook – автоматизация взаимодействия с устройствами по доступным протоколам с использованием родного для устройства синтаксиса команд, интеграция с Ansible, автоматизация обновления информации, дискаверинга новых устройств в сети. Множественное назначение расписания выполнения задач, мониторинг и приоритизация задач. Высокая горизонтальная масштабируемость модуля.
9. Модуль расследований – точечный инструмент для быстрого расследования событий на сетевом уровне, вывод, фильтрация и группировка SYSLOG событий, визуализация событий на таймлайне с возможностью быстрого перехода к соответствующему SYSLOG событию. Выгрузка отчёта по расследованию, база данных расследований.
10. Мультивендорность. Постоянно расширяемый список поддерживаемых устройств, быстрое (2-3 рабочих дня) и бесплатное добавление новых драйверов под заказчика в рамках обновления текущей версии ПО при наличии соответствующей лицензии в рамках поддержки.
Текущий список поддержки:
Mikrotik, Cisco, D-link, Tp-link, Eltex, HP, Huawei, Juniper, Vipnet, Вектор

11. Гибкая ролевая модель системы, интеграция с Keycloak, возможность работы с устройствами по сертификатам авторизации, без предоставления учётных данных системе.
12. Интеграция доступных модулей системы с Zabbix и Ansible, открытое API для внешних интеграций. Документация и консультация по работе с API слоем.

## Развёртывание

Пошаговая инструкция для Linux x86-64: [INITIAL_DEPLOYMENT.md](INITIAL_DEPLOYMENT.md).

<a id="start-here"></a>
### С чего начать

1. Получите у поставщика согласованный выпуск, лицензию и доступ к образам. Порядок получения файлов описан в [инструкции установки](INITIAL_DEPLOYMENT.md#get-release).
2. Подготовьте сервер и выберите один из четырёх вариантов ниже. Если PostgreSQL или Keycloak внешние, сначала передайте их администратору [требования к подключениям](docs/EXTERNAL-SERVICES.md).
3. Выполните подготовку и запуск из основной инструкции; проверьте состояния служб и вход администратора.
4. Создайте персональную учётную запись и выполните [первые действия с устройством](docs/README-FIRST-RUN.md#first-device).

Ресурсы сервера согласуйте по [условиям пилота](INITIAL_DEPLOYMENT.md#server). Если внешние службы требуют проверки сертификатов, сначала прочитайте [границы настройки TLS](docs/EXTERNAL-SERVICES.md#certificates): текущая поставка не подключает корпоративные CA автоматически.

Приложения поставляются готовыми Docker-образами. Доступны четыре варианта первоначальной установки:

1. [PostgreSQL и Keycloak вместе с UnicNet](INITIAL_DEPLOYMENT.md#all-local).
2. [Внешний PostgreSQL, встроенный Keycloak](INITIAL_DEPLOYMENT.md#external-postgres).
3. [Встроенный PostgreSQL, внешний Keycloak](INITIAL_DEPLOYMENT.md#external-keycloak).
4. [Внешние PostgreSQL и Keycloak](INITIAL_DEPLOYMENT.md#external-both).

В инструкции описаны требования, подготовка настроек, запуск, проверка результата и первый вход. Обновление существующего стенда требует отдельной процедуры.

<a id="delivery"></a>
## Статус поставки и поддержка

Текущая поставка Docker Compose предназначена для **пилотного развёртывания на Linux x86-64**. Приложения и инициализатор используют тег `rc-init-test`; встроенные службы — PostgreSQL 18 и Keycloak 26.7.0. Перечень возможностей выше описывает продукт; доступность функций в вашем пилоте определяется выданной лицензией.

Перед установкой обратитесь к представителю компании «ПРАВИЛЬНЫЙ СОФТ», передавшему поставку. Получите файл лицензии, реквизиты доступа к registry `cr.yandex` и согласуйте требования к серверу, объём пилота и канал технической поддержки. Лицензия и реквизиты выдаются отдельно и не входят в репозиторий.

Инструкция описывает первоначальную установку на одном сервере. Автоматическое обновление, резервное копирование и восстановление в эту поставку не включены. Настройку HTTPS, порядок сохранения данных и условия промышленной эксплуатации согласуйте с поставщиком отдельно. Подробности: [эксплуатация](docs/OPERATIONS.md) и [состав поставки](docs/DEPLOYMENT-DETAILS.md).

При обращении в поддержку укажите тег образов, выбранный вариант установки, команду с ошибкой и обезличенный фрагмент журнала. Порядок безопасной передачи диагностики приведён в [разделе о реквизитах и диагностике](docs/OPERATIONS.md#credentials).
